# Локальный чат внутри ридера

На этом Mac запуск уже настроен:

```sh
./start-reader.sh
```

Откроется `http://127.0.0.1:8765/#chat`. Терминал нужно оставить работающим. Для остановки нажми Ctrl+C. Повторный запуск при занятом порте откажет явно; действующий сервис не перезаписывается. Другой порт можно задать `--port 8766`.

Одна страница объединяет учебный ридер, настоящий локальный чат, историю и отдельный блок Lean. Qwen3-4B-Instruct-2507-4bit отвечает по-русски. DeepSeek-Prover-V2 и LoRA предлагают доказательства только по явно заданной Lean-задаче. Lean проверяет их отдельно. Одновременно две семьи моделей в памяти для генерации не удерживаются; после DeepSeek диалоговая модель перезагрузится при следующем вопросе.

Ни одно объяснение в чате не получает статус доказательства: метаданные фиксируют `lean_status: NOT_RUN`, даже если модель сама написала обратное. Условия, предложенные моделью, нужно вычитать. В блоке Lean до запуска видны исходный контекст, точное имя и тело. Кнопка проверки не означает проверку соответствия кода человеческому замыслу.

## Как настроить на другом Mac

Установи Python3.11, Elan/Lake и MLX-окружение:

```sh
python3.11 -m venv .venv-mlx
. .venv-mlx/bin/activate
python -m pip install -e .
python -m pip install -r requirements-mlx.txt
python scripts/install-dialogue.py --directory ../local-models/Qwen3-4B-Instruct-2507-4bit
./start-reader.sh
```

Установка скачает отдельные веса с закреплённой ревизии Hugging Face. После установки генерация использует локальные файлы. `chat_template.jinja` обязателен; одной папки с весами недостаточно. При запуске сервис загружает модель, проверяет шаблон, выполняет короткую генерацию и пробу Lean. Ошибка отображается в ридере. Свежая полная установка MLX-зависимостей на другом компьютере пока не сертифицирована.

Для кнопки DeepSeek укажи при установке дополнительные `--prover-model /path/to/DeepSeek` и `--adapter /path/to/LoRA`. Без них обычный чат работает, а генерация DeepSeek явно недоступна. Действующие веса не заменяются.

Локальная настройка хранится в `.local-dialog.json` и исключена из Git. Ответы сохраняются локально в `runs/local-reader/dialogue`; это обычные локальные записи, не подписанные свидетельства. Проверки Lean сохраняют отдельные run-каталоги.

## Публичная и локальная страницы

Публичная страница Чертогов содержит весь ридер и блок чата, но не делает сетевых запросов к твоему компьютеру. Запусти сервис и нажми «Открыть локальный ридер с чатом», либо используй автоматически открывшуюся страницу. Это тот же ридер с активным локальным подключением.

Не публикуй порт через туннель и не меняй адрес прослушивания на внешний. Сервис ограничен 127.0.0.1, проверяет Host, Origin и случайный токен локальной страницы. Он не разрешает CORS другим сайтам. Токен и содержимое переписки удаляются при экспорте офлайн-копии через кнопку ридера. Модель не получает средств исполнения команд; Lean-контекст при ручном запуске проверки должен оставаться доверенным.

## Текст прямо из терминала

```sh
python -m lean_proof_companion ask --model /path/to/dialogue-model "Что такое Lean 4?"
python -m lean_proof_companion chat --model /path/to/dialogue-model
```

`/exit` завершает диалог, `/reset` очищает контекст. Это диалоговая Qwen, а не DeepSeek/LoRA. Для проверяемого доказательства остаётся `prove` или отдельная кнопка Lean в ридере.
