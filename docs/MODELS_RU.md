# Какая модель на чём обучена

## DeepSeek-Prover-V2-7B

Базовые веса созданы внешними разработчиками DeepSeek. Мы используем локальную MLX-квантизацию; базовая модель не обучалась нами с нуля на ТЛФЛ.

## LoRA для ТЛФЛ

Сохранённый адаптер `tlfl_prover_v2_7b_lora` создавался для дообучения на Lean-примерах TMI-Lean-Formal-Library (ТЛФЛ). В сохранённом журнале Gemini есть завершение 100/100 шагов; на диске есть checkpoints50 и100 и итоговый адаптер. В конфигурации указаны100 итераций и8 адаптируемых слоёв. Экстрактор строил пары «условие → доказательство» из файлов библиотеки.

Это историческое происхождение, а не полная воспроизводимая аттестация конкретного учебного набора. Датасет позже пересобирался; новый split не отменяет старое знакомство адаптера с примерами. Точное восстановление первоначальных байтов и полная проверка учебных примеров остаются в родительском плане R01–R18.

Адаптация на примерах не означает полного знания библиотеки, истинности её аксиом, корректности всех формализаций или успешного решения любой её теоремы. Аксиомы проверяются отдельно для каждого доказательства. Рабочий адаптер при добавлении чата не переобучался и не заменялся.

## Qwen3-4B-Instruct-2507-4bit

Отдельная диалоговая модель, разрешённая владельцем для обычного русского текста. Веса скачаны из `mlx-community/Qwen3-4B-Instruct-2507-4bit`, revision `50d427756c6b1b2fe0c0a10f67fbda1fc8e82c1b`. Нами на ТЛФЛ не дообучалась. Полная библиотека автоматически в её контекст не загружается; есть краткие инструкции о ролях инструментов и малом примере карточки.

Qwen объясняет и предлагает черновики. DeepSeek предлагает доказательство фиксированной Lean-задачи. Lean проверяет его тип и зависимости. Слова модели не заменяют последний шаг.
